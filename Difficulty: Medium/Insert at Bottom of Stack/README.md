<h2><a href="https://www.geeksforgeeks.org/problems/insert-an-element-at-the-bottom-of-a-stack/1">Insert at Bottom of Stack</a></h2>
<h3>Difficulty Level : Easy</h3>
<hr>

<div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);">

<p>
<span style="font-size: 18.6667px;">
Given a stack <strong>st</strong> containing <strong>n</strong> integers and an integer <strong>x</strong>, insert <strong>x</strong> at the bottom of the stack.
</span>
</p>

<p>
<span style="font-size: 18.6667px;">
<strong>Note:</strong> While displaying the stack, the bottommost element is printed first.
</span>
</p>

<p>
<span style="font-size: 14pt;"><strong>Examples:</strong></span>
</p>

<pre>
<strong>Input:</strong> st = [4, 3, 2, 1, 8], x = 2
<strong>Output:</strong> [2, 4, 3, 2, 1, 8]
<strong>Explanation:</strong> After insertion of 2, the final stack
will be [2, 4, 3, 2, 1, 8].
</pre>

<pre>
<strong>Input:</strong> st = [5, 3, 1], x = 4
<strong>Output:</strong> [4, 5, 3, 1]
<strong>Explanation:</strong> After insertion of 4, the final stack
will be [4, 5, 3, 1].
</pre>

<p>
<span style="font-size: 14pt;"><strong>Constraints:</strong></span><br>
<span style="font-size: 14pt;">
1 ≤ n ≤ 10<sup>5</sup><br>
0 ≤ x, elements of stack ≤ 10<sup>9</sup>
</span>
</p>
</div>
